# YNX source document archive

These files preserve their exact original bytes and SHA-256 digests. They are technical drafts and historical source material, not current operating instructions. Read the current capability notice and the document version in the website reader before using any material. Older validator commands and public contract deployment examples may not match current software.

The current public network uses one authoritative producer and authenticated read-only followers. Permissionless validators, staking and reward distribution are not open. A local consensus experiment is not a public network deployment.

See manifest.json for source identity, dates, category and per-document review flags. UI translations do not imply translated source bodies.
