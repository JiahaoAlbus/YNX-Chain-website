# 支持、安全报告、争议与退款

版本：1.0.0-candidate  
状态：工作流规范；尚无公开支持 URL 和有人值守服务的证据

YNX 运营者绝不会索取助记词、私钥、验证者密钥、PEM 文件、CVV 或完整 API 秘密。在 `public-product-metadata.json` 公布官方支持 URL 之前，用户不应相信声称可以找回资金或账户的非官方联系人。

支持受理应分配案件 ID，并只收集产品、网络、大致 UTC 时间、适用时的公开交易哈希、不含秘密的请求或错误 ID、用户可见消息，以及简要说明。敏感证据使用获准的私密渠道，不通过公开 issue 或链状态传递。

安全报告需要经法律顾问批准的安全港与披露条款、严重性分级、确认收到的目标时间、加密证据渠道、协调披露、修复负责人，以及向报告者提供更新。仍处于遏制阶段时，不要在公开状态页发布利用细节。

交易争议应区分提交、服务商确认收到、纳入区块、结算和应用回执。已最终确定的公链交易可能不可逆。YNX 不能仅因结果不利，就撤销用户授权的规范交易。账户失陷、重复执行、服务商不匹配和界面误导，需要证据审阅。

商户退款是新的价值转移操作，受商户条款、付款方与收款方验证，以及权威结算证据约束。应用中的退款记录不能证明资金已退回。批准前必须披露费用、时间、汇率影响和不可用路径。

有关 Trust 标签的申诉遵循 `docs/trust/TRUST_APPEALS_MARKET_INTEGRITY.md`。隐私请求必须区分可删除的链下数据和不可变的公开链记录。在具备人员轮值和路由测试前，不设定响应时间承诺。
