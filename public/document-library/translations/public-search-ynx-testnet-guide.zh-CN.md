## 直接回答

YNX Testnet 是 YNX Chain 的测试网络。它使用 EVM 链 ID 6423（`0x1917`）、Comet/Cosmos 链 ID `ynx_6423-1`，并以 YNXT 作为原生测试网资产。测试资产不代表货币价值，也不保证流动性。

## 钱包安全

使用隔离的测试网账户。绝不要在网站、支持消息、AI 提示或文档表单中输入助记词或私钥。自定义网络请求只应添加或切换到预期网络，并重新检查所选链。添加网络不得自动请求账户或交易。

签名前审阅接收方、金额、精确费用、nonce、链 ID 和交易哈希。结果未知不等于成功：在考虑再次提交前，先按哈希、发送方和 nonce 查询权威状态。

## 获取测试网 YNXT

Faucet 必须验证目标地址、报告限流，并返回真实交易或证据结果。仅有 Faucet 界面响应并不足够。如果公开 Faucet 不可用或未经验证，不要使用非官方服务商，也不要声称已成功到账。

## 开发者使用

源码包含 Hardhat、Foundry、SDK 和合约验证工作流。兼容性仅限于经过测试的方法和构建产物，不代表通用以太坊兼容。在链身份、字节码、源码、小数位数、符号和授权主体得到验证之前，不要发布代币或合约地址。

## 最终性与派生服务

已提交链状态具有权威性。Explorer 和 Indexer 记录是派生数据，可能滞后、重建或不可用。钱包或服务应分别展示待确认、已提交、失败和未知状态，并注明来源与观察时间。

## 跨链桥与稳定币提示

本文不声称存在已上线的 Bridge 或官方稳定币路径。本地 Bridge 协调器已禁用外部执行，稳定币服务仅记录不执行操作的审阅意图。不要向未经批准的跨链桥或稳定币合约发送价值。

## 测试网与主网

测试网代码、余额、验证者、软件包和端点不能证明主网已成立。生产签名、托管、经济政策、法律审阅、公开容量和独立安全证据，都需要单独的发布记录。

## 故障排查

- 链 ID 错误：停止，不要签名或提交。
- 端点不可用：显示失败，稍后重试；不要虚构健康状态。
- Explorer 数据过期：与权威 RPC 和来源时效比较。
- Faucet 拒绝：保留原因与限流状态；不要声称产生了交易。
- 交易结果未知：重试前按哈希和发送方 nonce 查询。
- 可疑的秘密信息请求：停止，并在官方支持或安全报告地址公布且验证后，通过该途径处理。
